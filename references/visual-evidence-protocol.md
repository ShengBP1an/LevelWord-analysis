# 图像证据协议

示意图用于让读者复核空间判断，不能为了配合结论改变证据。

## 完整案例最低图像组合

1. 原始总览图：确认整体形状、方向、目标和版本；
2. 抽象拓扑图：表达节点、连接、分层、汇聚与回流；
3. 动线标注图：对应主要、侧翼、高层、撤离和复战路线；
4. 功能分区图：对应出生、缓冲、交战、控制和危险区域；
5. 局部实机图：证明高低差、视线、掩体、入口或 Landmark；
6. 前后版本图：仅在分析改版时强制，尽量同朝向、同比例、同图例。

每项主要空间判断引用具体图号。没有可靠图片时写“缺少图像证据”，不要补造。

## 图片身份

### 原始证据图

官方图、当前版本截图、实机帧、白盒和开发者材料。保留原文件，不覆盖；标明来源、版本、日期和录像时间码。

### 分析标注图

在原图副本上添加最少必要的箭头、编号、虚线、半透明区域和图例。不得遮挡关键入口、掩体、目标或替代路线。

### 抽象分析图

可以重绘节点和连接，但必须注明：

> 分析示意图，根据当前版本实机材料抽象，不是官方平面图。

不得添加没有证据支持的通路、入口或垂直连接。

### 方案概念图

用于表达新增路线、掩体或高台。与原图分开，注明“方案设想，尚未实装”，并展示未修改基准图、修改理由、预期行为和副作用。

## 禁止操作

- 移动、删除、补画或生成原地图结构；
- 用生成式填充补全看不清的区域；
- 将不同版本或模式拼成一张事实图；
- 为强化结论改变比例、透视或局部位置；
- 裁掉不利于当前结论的替代路线；
- 调整色彩和明暗，使路线显得更危险或重要；
- 未说明就镜像、旋转、拉伸或重投影；
- 用 AI 生成图、概念图或玩家重构图作为官方或实机证据。

## 允许的非破坏处理

可以裁切无关 UI、等比例缩放、记录后旋转、添加编号/箭头/透明色块/视线/图例、前后版本并排、遮挡敏感信息，或单独重绘抽象拓扑。所有处理在副本上完成并记录，不覆盖原图。
