# 标注与图版规范

## 一图一问

每张分析图只解决一个主要问题，例如首次分流、两条路线的时间与暴露、高点覆盖、核心区流量或版本改动。不要把全部路线、区域、视线、角色和改动挤在同一张图上。

## 标注语义

- 实线箭头：可确认的主要移动；
- 虚线箭头：条件式、推测或方案路线；
- 半透明色块：功能区域；
- 细虚线：视线或火力覆盖；
- 圆点：节点、目标或关键站位；
- 星号或警示符号：交火、阻塞或高风险点。

颜色只辅助区分，不单独承担含义；同时使用文字、编号或线型，照顾色觉差异。

## 版面要求

- 保留方向；旋转时记录原始方向和角度；
- 路线起终点使用相同命名贯穿正文；
- 标注不覆盖入口、掩体、目标或关键地形；
- 前后对比使用相同裁切、朝向、比例和图例，做不到就说明；
- 局部图附总览定位小图或区域编号；
- 优先使用编号和短标签，避免大面积不透明覆盖。

图上只写事实或中性功能，如“A 主攻线”“高位观察”“单向落点”。“无敌点位”等评价写在正文并提供证据。

## 原图与衍生图

重要结论保留未标注原图、对应标注副本，以及含来源、版本和处理说明的图注。方案额外保留基准图和方案图，不能只展示改后效果。

抽象图声明：

> 分析示意图，根据当前版本材料抽象，不是官方平面图。

方案图声明：

> 方案设想，尚未实装。虚线或指定颜色为新增、删除或调整内容。

## 图像交付检查

- [ ] 原图未覆盖
- [ ] 图号与正文一致
- [ ] 来源、版本和时间可追溯
- [ ] 处理内容已记录
- [ ] 标注未遮挡关键空间
- [ ] 没有混用版本或模式
- [ ] AI 或概念图未当作案例证据
- [ ] 方案图与基准图并列
- [ ] 抽象关系没有超出证据
- [ ] 图片实际支持对应结论
