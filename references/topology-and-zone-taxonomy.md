# 拓扑、区域与战斗空间分类

## 抽象拓扑

先移除美术，只保留核心与次级节点、汇聚分流回流、垂直层、出生到战区的路径、目标、机关和单向或角色限定连接。按实际结构选择主轴＋环路＋高层、Hub＋Ring、多竞技场网络、攻防走廊或非对称目标网络；不要强行套三路图。

检查连通性、路径冗余、转点成本、视线、信息、暴露和撤离。

## 功能区域

| 区域 | 核心问题 |
|---|---|
| 出生保护区 | 是否提供短暂安全并避免无解压制 |
| 分流/缓冲区 | 是否让玩家恢复判断并快速选路 |
| 次级交战区 | 是否产生有意义事件而非纯跑图 |
| 核心战斗区 | 为什么流量、信息或目标在此汇聚 |
| 信息/控制区 | 是否支持下一步判断与短期控制 |
| 转换/危险区 | 是否在进入、退出或跨层时改变风险 |
| 回流/恢复区 | 是否帮助受压方重组并重新入场 |

功能区数量不固定。对每区写位置、边界、进入退出、风险收益、预期行为、相邻状态变化和失效风险。

## 目的导向动线

- 直接路线：最快接敌，通常信息多、暴露高；
- 掩护路线：以距离换遮挡；
- 高层路线：换取信息、枪线或短期控制；
- 隐蔽路线：以较少信息换低暴露；
- 撤离/回流线：受压后恢复并换角度再入场；
- 复战线：重生到下一次有效选择和接战。

比较时间、暴露、信息、交火距离、入口、角色可达性、目标收益、撤离和反制，并写成玩家动作链。

## 阻塞点

- Hard Choke：多数玩家必须通过；
- Soft Choke：短暂聚流且有替代路线；
- Transition Choke：安全状态向暴露状态切换；
- Information Choke：出口信息不足，易伏击或被预瞄。

说明形成原因、控制收益、通过风险和反制。窄口没有流量或状态转换时，只是窄通道。

## 高低差

区分信息位、短期火力位和统治位。分析入口、进入时间、角色门槛、高层互通、撤离、视线、火力和低打高反制，不能只写“高打低有优势”。

## 出生与复战

理想状态是“短暂安全＋快速分流＋可恢复的复战成本”，不是单纯离战场近。检查保护、出口、第一次有效选择、Runback、压家路径和失败方重组能力。

## Landmark 与整体循环

Landmark 分视觉、结构和功能三类，检查是否支持定位、报点、选路和战斗。最终还原为：

**发现敌人 → 接战 → 击败或受压 → 脱离与转点 → 换枪线 → 重新接战**

寻找寻敌过久、纯跑图侧路、固定高点垄断、单一入口、出生压制、死胡同和路线收益趋同等破坏因素。
