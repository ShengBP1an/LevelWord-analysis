# BreakLD 地图分析 Skill

一个面向多人和合作游戏关卡的系统分析工具。它不只描述地图“有什么”，更关注空间设计如何影响玩家选择、行为循环与核心体验。

## 能做什么

- 完整地图研究与版本对比
- 动线、区域、阻塞点、高低差和复战分析
- 参考案例迁移与地图优化建议
- 带来源、指标和示意图的分析报告

## 分析方法

**模式需求 → 空间结构 → 行动成本与信息变化 → 玩家选择 → 行为循环 → 核心体验 → 验证指标**

分析会核对当前版本与可靠来源，区分事实、观察、推断和假设，并明确区分原图、标注图、抽象图与方案图。

## 使用示例

```text
使用 $break-ld-analysis，分析这张多人地图的空间结构、玩家动线和战斗节奏。
```
